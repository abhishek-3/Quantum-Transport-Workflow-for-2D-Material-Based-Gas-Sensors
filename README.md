# Quantum-Transport-Workflow-for-2D-material-Based-Gas-Sensors
A complete TranSIESTA/TBtrans 4.1-b4 workflow for computing quantum transport properties of 2D systems, including electrode SCF, scattering region NEGF calculations, bias-chaining, and sisl-based post-processing for transmission spectra, eigenchannels, I-V curves, and gas sensing analysis.
